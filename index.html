    🛠️ Troubleshooting

    If something does not work the first time, it is almost always one of the situations below. Each fix takes under a minute.

    The panel opens but the overlay does not appear in game

    This is usually a permissions issue. Close the utility completely, then right-click the file and choose Run as administrator again. Also check that Wardogs is running in windowed or borderless windowed mode rather than exclusive fullscreen, since overlays cannot draw over exclusive fullscreen on some graphics drivers.

    My antivirus blocked the file

    Some security programs flag any small utility that draws an overlay, even when the program is harmless. Open your security tool's quarantine or protection history, find the entry for Wardogs-utilite, and choose the option to restore and allow it. Then run the utility again.

    Nothing happens when I double-click

    Check that you are running the latest version, since older builds may not work with the current game patch. Also make sure Windows is fully updated — older builds of Windows 10 can block programs that use newer display features.

    The game stutters or the frame rate drops

    Turn off the ESP overlay and see if the stutter goes away. If it does, either lower the overlay's detail settings or run the game in borderless windowed mode, which handles background drawing more efficiently. Also close any browsers or video players you have open in the background.

    My settings were not saved

    Profiles are stored next to the program file, so if you move the file to a different folder, the utility loses track of your saved setup. Keep the file in a permanent folder rather than running it straight from a temporary directory. Re-saving after the move will fix it.
